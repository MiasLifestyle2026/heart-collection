MIA’S LIFESTYLE – THE HEART COLLECTION
Mobile Web App – Version 1

Enthalten: 110 Karten auf Englisch und Deutsch, Kategorien, Karten umdrehen, mischen, Favoriten (lokal), Kartenlinks teilen, offline-faehige PWA nach erstem Laden.

SO TESTEST DU DIE APP:
1. ZIP entpacken.
2. index.html im Browser oeffnen. Die Grundfunktionen laufen lokal.
3. Fuer eine echte Handy-URL den gesamten Ordner bei Netlify Drop, Cloudflare Pages oder einem anderen statischen Hoster hochladen. HTTPS aktivieren.
4. Auf dem Handy die Website oeffnen und ggf. Zum Startbildschirm hinzufuegen.

WICHTIGE GRENZE:
Dies ist ein funktionsfaehiger Einzelspieler-Prototyp, KEIN synchronisiertes Zwei-Personen-Spiel. 'Karte teilen' teilt einen Link zur gleichen Karte; es gibt noch keine gemeinsamen Raeume, Live-Synchronisation, Nutzerkonten oder Bezahlfunktion. Fuer Couple Mode benoetigen wir ein Backend (z.B. Supabase) mit Raumcodes, Zugangsschutz, Echtzeit-Synchronisation und Datenschutzregeln.

Vor einem Verkauf: Texte und Uebersetzungen pruefen, rechtliche Angaben/Datenschutz und Zahlungsabwicklung ergaenzen, Hosting und Sicherheitspruefung durchfuehren.
